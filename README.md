# G-Link: CST Guest House Booking System

Capstone project, BE Software Engineering, College of Science and Technology (RUB).

| Folder | What it is | Branch |
|---|---|---|
| `database/` | MySQL tables (12) and starting data | `database` |
| `server/` | Express + Node.js API | `backend` |
| `client/` | React (Vite) website | `frontend` |

**Start here:** read `SETUP_GUIDE.md`. It explains, step by step, which folder goes into which branch, how to run each part, every page, and how to test every flow from the System Flow and Data Types documents.

Quick run (after setup):

```
# terminal 1
cd server
npm run dev

# terminal 2
cd client
npm run dev
```

Open http://localhost:5173
